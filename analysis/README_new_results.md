# New FMG analyses (not in the manuscript)

This directory contains additive code for analyses proposed in the review note. No manuscript, canonical notebook, archived result, seed list, split rule, or primary model setting is edited here. All numerical outputs created here must be treated as **NEW and not yet in the paper** until reviewed and deliberately integrated by the authors.

## Files and intended manuscript use

| File | What it produces/supports | Potential manuscript destination |
|---|---|---|
| `fmg_decomposition.py` | Per-seed decomposition into accuracy, all-sample and subgroup recall losses, specificity loss, predicted-positive-rate changes, and the FMG identity; summary and correlations for MCAR and the existing group-conditional MAR mechanism. | Candidate Table S7-style decomposition table and a new descriptive supplement figure/table. It does not alter existing Table 3. |
| `extend_public_health_s7.py` | Reconstructs the existing public-health conditions and adds clean focus/comparison recall, comparison recall loss, DiD, and overall/group dPPR. Before saving, it verifies already-reported metrics against the original `metrics_per_mask.csv`. | Candidate extension Table S7. Any rows generated by this add-on are NEW; the pre-existing outcomes remain archived separately. |
| `threshold_sensitivity.py` | Compares class-weighted models (or the stated MLP threshold proxy) with a threshold calibrated only from clean training scores and training prevalence. | Candidate threshold-sensitivity table. Thresholds are exploratory; this is not an operational threshold recommendation. |
| `audit_checklist.py` | Summarizes per-seed FMG, accuracy loss, subgroup recall losses, clean focus recall, and DiD using fixed, named descriptive flags. | Internal interpretation/reporting helper; not a new result by itself. |
| `FMG_additional_analyses_runner.ipynb` | Jupyter interface for setting data paths, checking versions, calling the analysis scripts, and running tests. It is a separate runner; the canonical research notebook is untouched. | Convenient execution interface; it adds no results by itself. |
| `tests/test_analysis_helpers.py` | Tests the algebraic identity, archived Adult Table 3 means, and reporting rules/schema conversion. | Reproducibility/quality-control tests, not manuscript evidence. |
| `run_manifest_analysis.json` | Versions, commit, commands, elapsed times, source/output hashes, and run limitations for this analysis package. | Candidate reproducibility supplement / data availability record. |
| `fmg_additive_analysis_archive.zip` | Archive of the new analysis source, tests, README, and validation-attempt log. It excludes the manifest to avoid embedding a stale self-hash. | Reproducibility attachment for review; it contains no manuscript edits or new empirical table where validation failed. |

## Required inputs and reproducibility

To run interactively, open `FMG_additional_analyses_runner.ipynb` in Jupyter/VS Code after starting Jupyter from the repository root. Run cells top to bottom, edit the path variables in the data-path cell, then run the relevant analysis section. In Colab, first place the repository and scripts in the runtime and set paths to uploaded or mounted datasets. The notebook reports version mismatches but does not silently install or upgrade packages.

Primary decomposition and primary threshold runs require raw Adult, COMPAS, and Taiwan files (and optional exploratory German Credit from OpenML). The scripts refuse primary exactness claims unless the environment matches `run_manifest_20261025.json`. The pinned primary versions are those recorded there and in the first notebook cell; do not upgrade them. Example:

```powershell
python analysis/fmg_decomposition.py --adult PATH_TO_ADULT_ZIP --compas PATH_TO_COMPAS_CSV --taiwan PATH_TO_TAIWAN_CSV --german-openml
python analysis/threshold_sensitivity.py --adult PATH_TO_ADULT_ZIP --compas PATH_TO_COMPAS_CSV --taiwan PATH_TO_TAIWAN_CSV --german-openml
```

Public-health runs require the raw input paths. The BRFSS 2024 file is not stored in this repository. The UCI ZIP can be supplied as `--diabetes-zip PATH_TO_UCI_ZIP`. The S7 add-on reads existing outputs without modifying them and writes to a separate output path:

```powershell
python analysis/extend_public_health_s7.py --diabetes-zip PATH_TO_UCI_ZIP
python analysis/extend_public_health_s7.py --brfss PATH_TO_BRFSS_XPT_OR_ZIP --diabetes-zip PATH_TO_UCI_ZIP
python analysis/audit_checklist.py analysis/outputs/public_health/public_health_s7_style_new.csv
```

For the threshold analysis, use `--extension-only` with either or both extension source paths. It uses the seeds represented in the archived extension outputs and the extension's recorded software pins. The MLP does not support the requested class-weight setting in these configured implementations; its class-weight alternative is explicitly labeled as a clean-training prevalence-threshold proxy. A scalar threshold may not achieve an exactly matching training predicted-positive rate when scores tie; the achieved training rate is recorded.

## Current limitations

- The primary run cannot be independently recomputed in this workspace unless all raw primary files are provided and the exact pinned primary environment is available. A cross-version rerun must not be substituted for the requested exact archive comparison.
- The BRFSS 2024 raw XPT/ZIP input was not provided here, so no BRFSS numbers are generated by the add-on.
- Only regenerated metrics are written as outputs. Missing predictions are never reconstructed from aggregate metrics or guessed.
- Repeated seeds are benchmark split conditions, not independent deployment populations. dPPR is a predicted-positive-rate contrast and is not itself a fairness or safety certificate.
- Existing public-health outputs and the original audit implementation remain unchanged; new S7-style files are separate and clearly labeled.
